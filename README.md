# Optimal Transport in Space Imaging
### CSUREMM Research Project  
Emma Jia Ethan Sharma Raymond Zhao

This repository is for our research project about black hole imaging. Our work consists of developing a image/video reconstruction framework involving Optimal Transport, intentionally building on existing image reconstruction methods developed by the Event Horizon Telescope (EHT) team. Further, we develop an Optimal Transport-based evaluation metric named Optimal Transport Path Consistency (OTPC), specifically intended for dynamic imaging cases such as our object of study Sagittarius A*. The majority of our code writing was AI-assisted. We also include our Appendix B table of warm sweep results, which could not fit in our research paper (aiming to publish).

## Libraries Used

For sampling / reconstruction functions used in our files, download the [ehtim library](https://github.com/achael/eht-imaging/).

Also used [inoisy](https://github.com/AFD-Illinois/inoisy) and [AART](https://github.com/iAART/aart) for black hole data simulation.
