# CSUREMM Research Project  
Emma Jia Ethan Sharma Raymond Zhao

This repository is for our research project about black hole imaging. Our work consists of developing a image/video reconstruction framework involving Optimal Transport, intentionally building on existing image reconstruction methods developed by the Event Horizon Telescope (EHT) team.

## Dependencies Required
For img_to_vid.py (Images to Video function)  
```
pip install opencv-python
```


For some sampling / reconstruction functions used in our files, download the [ehtim library](https://github.com/achael/eht-imaging/).

Also used [inoisy](https://github.com/AFD-Illinois/inoisy) and [AART](https://github.com/iAART/aart) for black hole data simulation.
