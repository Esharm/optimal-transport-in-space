# AART Black Hole Simulation Setup

We are attempting to simulate realistic (by a physicist's standard) black hole data, as close as we can to known reuslts about Sagittarius A*.

Clone AART:

git clone https://github.com/iAART/aart.git

Create environment:

python3.11 -m venv .venv-aart
source .venv-aart/bin/activate

Install dependencies:

pip install -r aart/requirements.txt
